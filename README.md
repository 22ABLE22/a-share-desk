# 沪深股票分析 · a-share-desk（个人学习版）

面向沪深个股 / ETF 的本地网页分析台：持仓盈亏、完整 K 线、经典指标信号、基本面速览、自选对比。

> 仅供学习研究，不构成投资建议。

## 功能

- **持仓总览**：成本、现价、市值、浮动盈亏、今日盈亏、仓位占比
- **实时提醒**：开市自动扫描持仓+自选，综合因子评分，推送买入/减仓关注
- **K线与信号**：日 K + MA / 布林 / 成交量；MA 金叉死叉、MACD、RSI、布林轨道
- **基本面**：PE / PB、市值、换手率，以及新手解读提示
- **自选对比**：多标的归一化走势对比
- **稳健参考**：同类利率债/货币/宽基/红利 ETF 科普清单
- **主题切换**：右上角按钮在「自动 / 浅色 / 深色」间循环，默认跟随系统

仓库内**不含**任何真实持仓数据。首次运行时会创建一个空持仓，你可在界面中自行添加：

| 字段 | 说明 |
|------|------|
| 代码 | 如 `159516`（可留空市场，程序自动判断 SH/SZ） |
| 数量 | 持股数（股 / 份） |
| 成本 | 你的成本价，用于计算浮动盈亏与摊薄 |

> `data/portfolio.json` 已被 `.gitignore` 排除，你的真实持仓与成本只留在本机，不会被提交。

## 数据说明

- **实时行情**：以新浪 hq 为主源（单标的 ~200ms），PE/PB/市值/换手率由腾讯 `qt.gtimg.cn` 补齐
- **搜索**：走新浪 suggest 单请求（~300ms），不依赖全市场大表
- **历史 K 线**：东财优先，失败自动回退新浪 → 腾讯；东财连续失败时断路器跳过它 120 秒，避免每次白等超时
- 行情可能有延迟，收盘价以交易所为准
- 持仓与自选保存在 `data/portfolio.json`（已 gitignore，仅存本机），可在界面中增删；提醒记录落盘 `data/alerts.json`
- 交易日历内置 2026 年沪深北官方休市安排（上证公告〔2025〕45号）；2027 年需补录 `market_clock.py`

## 常用操作

- 顶部搜索：输入 `159516`、`茅台` 等切换标的
- 添加持仓：持仓总览 → 添加持仓
- 添加自选：自选对比页输入代码后添加
- 实时提醒：侧边栏「实时提醒」→ 开启系统通知；开市自动扫描（也可立即扫描）
- 买卖点：K线与信号页查看经典指标，左侧有通俗趋势结论

## 实时监控

- 交易时段：工作日 09:30–11:30、13:00–15:00（北京时间）
- 扫描对象：持仓 + 自选，约 45 秒一次
- 综合分 0–100：≥72 买入关注；58–72 偏多；42–58 观望；30–42 偏空；<30 减仓/止损关注
- 浏览器通知需页面保持打开并授权
- 输出是观察建议，不是自动下单

## 关于 GPU / 开源模型

当前版本用**透明规则因子引擎**（均线、MACD、RSI、布林、量能、持仓成本），免费行情下更稳、可解释。后续可接 Qlib / FinRL / FinBERT 等开源项目做回测与情绪辅助。
